1. git init – Initialize a new Git repository.
2. git clone URL – Copy an existing repository from GitHub.
3. git status – Check the status of files.
4. git add filename – Stage a specific file.
5. git add . – Stage all changes in the current directory.
6. git commit -m "message" – Save staged changes as a commit.
7. git log – View commit history.
8. git log --oneline – View commits in a short format.
9. git branch – List existing branches.
10. git branch branch-name – Create a new branch.
11. git switch branch-name – Switch to another branch.
12. git switch -c branch-name – Create and switch to a new branch.
13. git merge branch-name – Merge another branch into the current branch.
14. git remote add origin URL – Connect your local repository to GitHub.
15. git push – Upload committed changes to GitHub.
16. git pull – Download and integrate changes from GitHub.
17. git show – Display details of a commit.
18. git checkout branch-name – Switch branches using the older command.
