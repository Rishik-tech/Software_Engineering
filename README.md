git init – Initialize a new Git repository.
git clone URL – Copy an existing repository from GitHub.
git status – Check the status of files.
git add filename – Stage a specific file.
git add . – Stage all changes in the current directory.
git commit -m "message" – Save staged changes as a commit.
git log – View commit history.
git log --oneline – View commits in a short format.
git branch – List existing branches.
git branch branch-name – Create a new branch.
git switch branch-name – Switch to another branch.
git switch -c branch-name – Create and switch to a new branch.
git merge branch-name – Merge another branch into the current branch.
git remote add origin URL – Connect your local repository to GitHub.
git push – Upload committed changes to GitHub.
git pull – Download and integrate changes from GitHub.
git show – Display details of a commit.
git checkout branch-name – Switch branches using the older command.
